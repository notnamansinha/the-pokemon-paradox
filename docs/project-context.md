## Project Objectives

1. **Investigate Population Distributions**: Characterize the general statistical dispersion, skewness, and variance of the six core base combat stats (HP, Attack, Defense, Sp. Atk, Sp. Def, Speed) across 1,219 unique Pokémon.
2. **Quantify Inter-Stat Relationships**: Utilize Pearson product-moment and Spearman rank-order correlation analysis to evaluate whether combat statistics scale independently or exhibit structured balancing.
3. **Validate Power Groupings**: Formulate and execute inferential hypothesis tests (Two-Sample Welch/Student T-Tests and One-Way ANOVA) to test whether human-defined power tiers ('Weak', 'Average', 'Strong', 'Legendary') correspond to statistically significant differences in combat capability.
4. **Discover Latent Combat Roles**: Apply unsupervised K-Means clustering on multidimensional standardized combat profiles to classify Pokémon into empirical battle archetypes (Walls, Sweepers, Tanks, Unevolved) and evaluate how elemental typing predicts role placement.
